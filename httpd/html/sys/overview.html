Help & Tips

Getting started

  1. Discover or add the controller on Controllers.
  2. Assign names and settings to its channels.
  3. Create Access Levels.
  4. Add credentials and assign at least one access level.

Controller networking

Use Docker host networking when the controller is on the local LAN. UHPPOTE discovery uses UDP broadcast on port 60000, which a bridge network commonly prevents.

Credentials

The controller decimal ID is FC × 100000 + CD. Duplicate credential numbers are blocked. Exact full names are grouped as one person who may have multiple credentials.

Access Levels

Level 0 is permanent No Access. Level 1 is permanent 24/7 access. Scheduled access is written to the controller so it continues working while this app is offline.

Relays and events

Relays represent physical controller channels. Open and Close change the relay mode; Controlled restores normal credential operation. Event search accepts names, credential numbers, FC/CD and controller IDs.

Data, backup and login

Persist /data to /DATA/AppData/uhppoted-httpd. Overview provides timestamped backups, safe restore and controller import. Administrators manage sign-in accounts from Login Accounts.

Tip: changes marked as synchronized were accepted by the controller. A local-only or synchronization warning means the controller should be checked before relying on that change.
